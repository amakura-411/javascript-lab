## お題

### 「非同期ジョブ実行マネージャー」

複数の処理を登録し、**同時実行数を制御しながら順番に処理するプログラム**を作ってください。

`Promise.all()` を呼んで終わり、では解けないようにします。

---

## 要件

ジョブには以下の情報があります。

- ID
- ジョブ名
- 処理時間
- 成功するか失敗するか

例えば5件登録した場合でも、すべてを同時には実行しません。

以下を満たしてください。

1. 複数のジョブを登録できる
2. 同時に実行できるジョブ数には上限がある
3. 1つのジョブが終了したら、待機中の次のジョブを開始する
4. 各ジョブについて以下の状態を確認できる

- 未実行
- 実行中
- 成功
- 失敗

1. ジョブが失敗しても、他のジョブは続行する
2. 全ジョブ終了後、実行結果を一覧表示する

実際のHTTP通信は不要です。

処理時間については、

「3秒かかる非同期処理」

のようなものを疑似的に再現してください。

---

## 制約

- Node.js上で動作するCLIでOK
- UI不要
- 外部ライブラリ不要
- `Promise.all()` に全ジョブをそのまま渡すだけは禁止
- 最初から高度な最適化はしない
- TypeScriptの場合、主要なデータに対して型を定義する

## 追加仕様

- 設定するジョブは、`tasks.json` で管理されている
  - 形式は以下の通り：

```json
[
  {
    "id": "001",
    "name": "JOB1",
    "processing_time": 10,
    "expectations": "success"
  },
  {
    "id": "002",
    "name": "JOB2",
    "processing_time": 3,
    "expectations": "failed"
  }
]
```

- 実行順序は、インデックスが若い順である
- 同時に実行できるジョブ数は3個まで
- 各ジョブの状態は1秒ごとに、ターミナルに表示される。
- 全てのジョブが完了したタイミングで、その結果が出力される

## 例外

| 状態                                                   | 振る舞い                                                             |
| ------------------------------------------------------ | -------------------------------------------------------------------- |
| ID を持たないタスク                                    | ID 未設定エラーとして、スキップする                                  |
| 同一IDを持つタスクが複数存在した                       | 最初に出現したタスクは実行。それ以外は重複IDエラーとしてスキップする |
| name が未設定                                          | 実行する。ログ上では `-` として表記                                  |
| processing_timeが未設定                                | 1秒として扱う                                                        |
| processing_time が 0より小さい場合                     | 設定不備として実行しない                                             |
| processing_timeが小数点                                | 切り上げ                                                             |
| processing_time が数値以外（null含む）                 | processing_time の設定不備としてエラーにする                         |
| processing_time が 10より大きい数値を設定した          | 10秒実行した上で、タイムアウトエラーにする（expectationsを無視）     |
| expectations未指定                                     | `success`が指定されたものとする                                      |
| expectationsに `success` `failed` 以外の値が設定された | 設定不備として実行しない                                             |
